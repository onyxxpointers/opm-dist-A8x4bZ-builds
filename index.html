Before you install

Windows: existing installs update themselves on next launch. You will be asked first.

Mac: the one-line command detects whether your Mac is Apple Silicon or Intel and installs the right build. Apple menu > About This Mac tells you which you have if you prefer to pick manually.

Mac builds are not notarized. If macOS says it cannot check the app, go to System Settings > Privacy & Security > Open Anyway. Installing with the one-line command usually avoids this entirely.
